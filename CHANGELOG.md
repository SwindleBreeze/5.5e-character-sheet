# Changelog

All notable changes, newest first. The version is in `package.json` and shown in the app under
Settings → About.

## 0.1.0

The first release candidate.

- Character creation wizard with explanations, level-up, undo, multiclassing and retraining.
- The sheet: Main, Combat, Spells, Inventory, Features, Extras, Description and Notes, with every
  number explained and d20 rolls a tap away.
- The Shop: every item of the books switched on, sorted by use, bought for a character.
- Import of packs, homebrew and data folders in the 5etools JSON format; backups to a file.
- Works offline and installs as an app; nothing leaves the device.
- The free rules (SRD 5.2) come with the app and load on first run: every class with its SRD
  subclass, species, backgrounds, feats, spells, equipment, magic items, rules and Beasts.
  Importing a book replaces the free rules it covers; characters keep working either way.
